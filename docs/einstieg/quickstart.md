# 2 · Quickstart: vom Karton zum ersten Sound

!!! note "Status dieser Seite"
    Gerüst – neu zu schreiben (kompakte Schritt-für-Schritt-Kurzform, verlinkt in die Detailkapitel).

!!! tip "Annahme"
    Die Complete wird **mit fertiger Firmware** ausgeliefert – Flashen ist nicht nötig.

Der kürzeste Weg:

1. **Einschalten** → ESPuino öffnet beim ersten Start einen WLAN-Access-Point.
   → [Details: Erststart](../inbetriebnahme/erststart.md)
2. **Mit dem AP verbinden** und das eigene WLAN eintragen.
3. **Webinterface öffnen** (`http://ESPuino.local` bzw. IP), Hostname setzen.
4. **Musik auf die SD-Karte** legen (oder ist schon drauf). → [Inhalte verwalten](../inhalte/verwalten.md)
5. **Karte zuweisen**: im Tab RFID eine Karte auflegen, Ordner/Datei + Playmode wählen, speichern.
6. **Karte auflegen → Sound.** 🎉
