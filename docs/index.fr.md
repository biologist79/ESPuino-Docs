# Manuel ESPuino

Bienvenue dans le manuel d'**ESPuino** – le lecteur audio piloté par RFID, construit autour d'un
ESP32.

Ce manuel réunit la documentation en un seul endroit. Les discussions, annonces et le support
continuent de vivre sur le [forum ESPuino](https://forum.espuino.de) ; ce manuel en est la
**source de référence**.

!!! info "Ce que couvre ce manuel"
    Ce manuel décrit la carte [**Complete**](hardware/complete.md) actuelle. Son prédécesseur
    direct, la **mini4L**, n'apparaît que sous forme de delta (chapitre 16). Les versions plus
    anciennes (premiers montages artisanaux, platines à bandes, cartes carrier) ne sont pas
    traitées.

!!! warning "État de la description : la branche `dev`"
    Ce manuel décrit toujours l'**état actuel de la branche `dev`** – c'est-à-dire ce qui a été
    intégré le plus récemment dans la version de développement. Si ton firmware provient de la
    branche `master`, il est donc possible qu'un réglage décrit ici te manque encore ou se présente
    différemment. Le [changelog](https://github.com/biologist79/ESPuino/blob/dev/changelog.md)
    indique ce qui a été ajouté et quand.
